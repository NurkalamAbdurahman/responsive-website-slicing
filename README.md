# 🐒 Tugas Akhir IT Club – Slicing Website "Monyet"

🔗 **Live Demo:** (https://website-monyet-nurkalamabdurahmans-projects.vercel.app/)

---

## 📖 Deskripsi

Proyek ini merupakan **tugas akhir IT Club kelas 11**, dengan fokus pada **slicing desain website bertema “Monyet”** menggunakan framework CSS modern.  
Slicing adalah proses mengubah desain visual (biasanya dari Figma atau mockup) menjadi kode **HTML dan CSS** yang siap dijalankan di browser.

---

## 🎯 Tujuan Proyek

- Memahami konsep dan proses slicing desain menjadi website.  
- Melatih penggunaan **framework CSS** untuk membuat antarmuka modern dan responsif.  
- Mengembangkan keterampilan teknis dalam **pengembangan front-end** berbasis HTML dan CSS.  
- Menumbuhkan ketelitian dalam meniru desain (layout, warna, tipografi, dan spacing).  

---

## 🧰 Tools & Teknologi

| Teknologi | Kegunaan |
|------------|-----------|
| 🧱 **HTML5** | Struktur utama halaman web |
| 🎨 **CSS3** | Styling dan layout halaman |
| ⚡ **Tailwind CSS** | Framework CSS untuk styling cepat dan responsif |
| 💻 **Visual Studio Code** | Text editor utama dalam proses pengembangan |

## 📂 Struktur Folder

```

│   ├── font/           # File font yang digunakan
│   ├── img/            # Gambar dan ikon
│   └── js/             # File JavaScript (jika diperlukan)
└── README.md           # Dokumentasi proyek
```

---
## 🚀 Cara Menjalankan Proyek

1. **Clone repository** atau **unduh file ZIP** dari project ini:
   git clone https://github.com/username/website-monyet.git
   cd website-monyet
2. Buka file `index.html` menggunakan browser (contoh: Chrome, Firefox, Edge).
3. Pastikan framework **Tailwind CSS** sudah terhubung (baik melalui CDN atau file lokal di `/assets/css`).
---

## 📋 Catatan Penting

* Pastikan hasil slicing **menyerupai desain asli** secara visual dan struktural.
* Gunakan **elemen HTML semantik** untuk menjaga struktur kode yang mudah dibaca.
* Pastikan tampilan **responsif** di berbagai perangkat (desktop, tablet, smartphone).
* Hindari penggunaan inline-style; gunakan class CSS untuk konsistensi styling.
